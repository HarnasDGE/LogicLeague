# LogicLeague

Podstawowy motyw WordPress dla LogicLeague.

## Instalacja

1. Skopiuj folder motywu do katalogu `wp-content/themes/` w instalacji WordPress
2. Zaloguj się do panelu administracyjnego WordPress
3. Przejdź do **Wygląd > Motywy**
4. Aktywuj motyw **LogicLeague**

## Struktura plików

- `style.css` - Główny arkusz stylów z nagłówkiem motywu
- `index.php` - Główny plik szablonu
- `header.php` - Nagłówek strony
- `footer.php` - Stopka strony
- `functions.php` - Funkcje i konfiguracja motywu

## Funkcje motywu

- Wsparcie dla miniaturek postów
- Wsparcie dla title tag
- Wsparcie dla RSS
- Rejestracja menu głównego
- Podstawowe stylowanie
